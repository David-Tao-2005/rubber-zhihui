# 橡胶智汇 V1 前端原型

这是一个无需安装依赖的移动端 Web App 原型。直接双击 `index.html`，或在该文件夹启动任意静态 Web 服务器即可预览。

已实现：

- 移动端首页与底部导航
- 行情卡片、图表和 AI 解读演示
- AI 问答交互与模拟回答
- 品质指标录入与规则化分析演示
- 病虫害图片上传界面
- 个人中心、种植管理、标准、溯源、科研中心入口

下一步接入：

1. 把 `app.js` 的 `mockAnswer` 替换为后端 `/api/chat` 调用。
2. 在后端接入大语言模型、向量知识库和文档解析。
3. 将行情、地块、批次、检测等演示数据替换为数据库/API 数据。
4. 将病虫害上传图片发送到后端视觉模型，并返回识别结果。

注意：生产环境中，API Key 只能保存在后端环境变量，不能写入网页代码。
